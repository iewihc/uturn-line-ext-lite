# UTurn 懶惰蟲（簡易版）

LINE Official Account Manager（chat.line.biz）的 Tampermonkey 腳本：聊天室工具列、派車、估價、選取「複製｜派車」等。

## 安裝／更新

1. Chrome 裝 [Tampermonkey](https://www.tampermonkey.net/)。
2. 點這個網址安裝：https://raw.githubusercontent.com/iewihc/uturn-line-ext-lite/main/uturn-line-ext.user.js
3. 之後有新版 Tampermonkey 會自動更新（@updateURL 指向這裡）。

## 關於收件匣

「收件匣」（多帳號同時監聽、司機對話、過跳通知、地圖試算）不在簡易版裡，需要另外安裝內部的 Chrome 擴充功能才會出現入口；沒裝的人這個腳本照常用。

這個 repo 只放 build 好的檔案，原始碼不公開。
